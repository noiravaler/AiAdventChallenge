# AI Challenge — workspace

Репозиторий-песочница для тестовых заданий **AI Challenge**. Каждая подпапка
`TaskNN` — отдельное тестовое задание со своей структурой и своим детальным
README (описывает только функционал этого задания).

## Общий функционал

Базовые возможности, общие для чат-приложений репозитория:

- **Go 1.22, почти только стандартная библиотека** — без внешних зависимостей;
  исключения — pure-Go драйвер SQLite (`modernc.org/sqlite`, без cgo) в
  заданиях с сохранением памяти и официальный MCP SDK
  (`github.com/modelcontextprotocol/go-sdk`, требует Go 1.26) в Task16
  (MCP-клиент), Task17_MCP (MCP-сервер) и Task20_MCP (MCP-сервер) (см. «Стек»).
- **OpenAI-совместимый API** — общение с любым совместимым endpoint
  (`POST {AI_BASE_URL}/chat/completions`): OpenAI, DeepSeek, OpenRouter, Groq,
  Ollama, LM Studio, GPUStack и т.д.
- **Режимы запуска**: локальная веб-страница-мессенджер (по умолчанию),
  терминальный чат (`-cli`), разовый запрос из командной строки
  (`ai-chat "промпт"`).
- **Потоковый вывод (SSE)** — ответ стримится в окно чата по мере генерации;
  `data: [DONE]` завершает поток.
- **Конфигурация** через переменные окружения, файл `.env` или флаги
  (`AI_API_KEY`, `AI_BASE_URL`, `AI_MODEL`, `AI_SYSTEM`, `AI_TIMEOUT`,
  `AI_MAX_TOKENS` и др.); приоритет: флаги > окружение > `.env`.
- **Системный промпт** и переключение модели.
- **История диалога** на сервере, кнопка «Новый диалог» (сброс),
  восстановление истории при перезагрузке страницы (`GET /api/history`).
- **Локальный сервер** на `127.0.0.1:5190` (порт берётся следующий свободный),
  переписка не покидает компьютер.
- **Боковое меню моделей** с активным списком и возможностью выбора.
- **Панель «Детали»** (`GET /api/debug`) — последний запрос/ответ и
  диагностика (ошибка API, «нет ответа», превышение лимита токенов, нарушение
  JSON-схемы).
- **Ползунки в интерфейсе**: максимальное число токенов и таймаут ответа.
- **Управление форматом ответа**: `text`, `json`, `jsonschema`,
  `jsonschema_structured` (strict) и `stop`-последовательность.
- **Резервный провайдер `[reserve]`** — независимый OpenAI-совместимый
  эндпоинт, отдельный от основного, включается, когда основной недоступен.
- **Поддержка reasoning-моделей** (`reasoning`/`reasoning_content`) — трейс
  думающей модели не показывается, но считается «активностью» и не даёт
  оборвать долгую генерацию.
- **Структура типового задания**: `app` (точка входа/CLI), `server`
  (HTTP-сервер), `api` (HTTP-клиент API), `config` (конфигурация),
  встроенная static-страница (`go:embed`).

Из orbit в самостоятельный сервер **Affirm MCP** (папка `Task20_MCP`, порт 5200) вынесены аффирмации и перевод — 3 инструмента: `daily_affirmation` (намеренный дубль имени с orbit — коллизия разрешается префиксом `affirm__daily_affirmation`), `translate_text`, `affirmation_status`. Автозапуск (`mcpboot`) обобщён на оба локальных сервера: перед подключением чат проверяет `/api/status` orbit **и** affirm и сам поднимает ещё не запущенные (независимые env `AI_MCP_DIR`/`AI_MCP_AFFIRM_DIR`, `AI_MCP_BIN`/`AI_MCP_AFFIRM_BIN`, `AI_MCP_LOG`/`AI_MCP_AFFIRM_LOG`). В блоке «MCP» у локальных серверов — кнопка **остановки/подъёма процесса**, независимая от тумблера вкл/выкл: «стоп» (`POST /api/mcp/stop`) роняет процесс и сессию, но **инструменты остаются у модели** — вызовы возвращают ошибку, как при реальном отказе сервиса (авто-реконнект остановленный не трогает); «поднять» (`POST /api/mcp/start`) перезапускает процесс и подключается; в `/api/mcp` — поля `stopped`/`local`/`process`. Блобы дополнены группой «Affirm» и группой **«Все MCP»** — сценарии, требующие инструментов всех трёх серверов сразу (цены dubai + астрология orbit + аффирмации/перевод affirm, включая кейс коллизии имён). |
| `Task20_MCP` | **Отдельный MCP-сервер аффирмаций (вынос из orbit)** — из Task17_MCP в самостоятельный сервер `affirm-mcp` (папка `Task20_MCP`) вынесены сервисы аффирмаций и перевода: affirmations.dev (без ключа) и бесплатный Google Translate (`client=gtx`) — 3 инструмента: `daily_affirmation` (аффирмация дня на русском + волшебный смайлик), `translate_text` (произвольная пара языков) и `affirmation_status` (диагностика провайдеров). Сервер полностью без состояния; два транспорта (stdio и Streamable HTTP `/mcp` на `127.0.0.1:5200`) + мини-страница статуса; режимы `-list`/`-probe`; env `AFFIRM_URL`/`AFFIRM_TIMEOUT`/`AFFIRM_TRANSLATE_URL`; офлайн-тесты на фейковых httptest-серверах. |

## Стек

- Go 1.22, стандартная библиотека; внешние зависимости по заданиям:
  pure-Go драйвер SQLite (`modernc.org/sqlite`, без cgo) для хранения
  памяти (Task11+), пульса неба (Task17_MCP) и планировщика (Task18), и
  официальный MCP SDK (`github.com/modelcontextprotocol/go-sdk`,
  требует Go 1.26) для MCP-клиента в Task16 и MCP-серверов в Task17_MCP
  и Task20_MCP.
- HTTP-клиент, Server-Sent Events, встроенная static-страница (`go:embed`).
- Конфигурация: `.env` + переменные окружения.
