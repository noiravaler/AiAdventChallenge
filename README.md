# AI Challenge — workspace

Репозиторий-песочница для тестовых заданий **AI Challenge**. Каждая подпапка
`TaskNN` — отдельное тестовое задание со своей структурой и своим детальным
README (описывает только функционал этого задания).

## Общий функционал

Базовые возможности, общие для чат-приложений репозитория:

- **Go 1.22, только стандартная библиотека** — без внешних зависимостей.
- **OpenAI-совместимый API** — общение с любым совместимым endpoint
  (`POST {AI_BASE_URL}/chat/completions`): OpenAI, DeepSeek, OpenRouter, Groq,
  Ollama, LM Studio, GPUStack и т.д.
- **Режимы запуска**: локальная веб-страница-мессенджер (по умолчанию),
  терминальный чат (`-cli`), разовый запрос из командной строки
  (`ai-chat "промпт"`).
- **Потоковый вывод (SSE)** — ответ стримится в окно чата по мере генерации;
  `data: [DONE]` завершает поток.
- **Конфигурация** через переменные окружения, файл `.env` или флаги
  (`AI_API_KEY`, `AI_BASE_URL`, `AI_MODEL`, `AI_SYSTEM`, `AI_TIMEOUT`,
  `AI_MAX_TOKENS` и др.); приоритет: флаги > окружение > `.env`.
- **Системный промпт** и переключение модели.
- **История диалога** на сервере, кнопка «Новый диалог» (сброс),
  восстановление истории при перезагрузке страницы (`GET /api/history`).
- **Локальный сервер** на `127.0.0.1:5190` (порт берётся следующий свободный),
  переписка не покидает компьютер.
- **Боковое меню моделей** с активным списком и возможностью выбора.
- **Панель «Детали»** (`GET /api/debug`) — последний запрос/ответ и
  диагностика (ошибка API, «нет ответа», превышение лимита токенов, нарушение
  JSON-схемы).
- **Ползунки в интерфейсе**: максимальное число токенов и таймаут ответа.
- **Управление форматом ответа**: `text`, `json`, `jsonschema`,
  `jsonschema_structured` (strict) и `stop`-последовательность.
- **Резервный провайдер `[reserve]`** — независимый OpenAI-совместимый
  эндпоинт, отдельный от основного, включается, когда основной недоступен.
- **Поддержка reasoning-моделей** (`reasoning`/`reasoning_content`) — трейс
  думающей модели не показывается, но считается «активностью» и не даёт
  оборвать долгую генерацию.
- **Структура типового задания**: `app` (точка входа/CLI), `server`
  (HTTP-сервер), `api` (HTTP-клиент API), `config` (конфигурация),
  встроенная static-страница (`go:embed`).

## Сводная таблица заданий

| Папка | Краткое описание |
| ----- | ---------------- |
| `Task01` | Базовый AI-чат: веб/CLI/разовый запрос, потоковый вывод (SSE), конфигурация через `.env`, история диалога. |
| `Task02` | Расширенный чат: резервный провайдер `[reserve]`, reasoning-модели, форматы ответа, панель «Детали», динамический список моделей, ползунки. |
| `Task03` | Решатель задач: список задач, способы решения, два уровня рассуждения (low/high), блок «Вывод» с анализом, гибкая проверка ответа. |
| `Task04` | Эксперимент с настройками модели: две задачи рядом, матрица результатов (3 температуры × 5 прогонов), проверка ответа, блоки «Вывод» и «Общий вывод», повтор при ошибке/таймауте. |
| `Task05` | Сравнение трёх классов моделей на списке задач: задачи-аккордеоны, запуск всех задач всеми моделями (маленькая/средняя/флагманская), три таблицы результатов с «Итоговой стоимостью» и блок «Вывод». |
| `Task06` | Чат с инструментами (function calling): `get_current_time`, `roll_dice`; пошаговая панель «Шаги» (токены + время), ползунок числа циклов, Markdown-форматирование, быстрые сообщения (блобы). |
| `Task07` | Чат с инструментами + хранение контекста по агенту: персистентность диалога по каждой модели (файлы в `history/`), ретенция записи 3 дня, история в UI (приглушённые сообщения, разделение по дням, время hh:MM). |
| `Task08` | Токен-аккаунтинг и вложения: панель «Количество токенов» с метрикой «Токены истории диалога», токены по каждому раунду в «Шагах», меню «+» с готовыми текстами (150 000 / 300 000 токенов) для воспроизведения текстовых кейсов, понятные ошибки больших запросов. |
| `Task09` | Тестовые сценарии и сжатие контекста: блоб «Диалог про шторы» загружает готовый диалог в контекст (без викторины), меню «+» отправляет вопросы викторины с пометкой «Ожидаемый ответ», пункт «Сжать контекст» заменяет старые сообщения сводкой от модели (ползунок «Размер контекста», блок «Сжатие» в «Деталях»). |

Подробное описание каждого задания — в соответствующем `TaskNN/README.md`.

## Стек

- Go 1.22, только стандартная библиотека.
- HTTP-клиент, Server-Sent Events, встроенная static-страница (`go:embed`).
- Конфигурация: `.env` + переменные окружения.

## Как запустить

```sh
cd Task01
go run ./app           # веб-чат (откроется браузер)
go run ./app -cli      # терминальный режим
go build -o bin/ai-chat ./app
```

> Секреты в `.env` исключены через корневой `.gitignore` и не попадают в
> репозиторий.
