Краткосрочный слой хранит реплики диалога (в промпт идут последние сообщения окна); рабочий — задачу (обновляется сжатием Summary/Sticky Facts), заметки (task_note) и факты ветки (попадают в каждый запрос); долговременный — профиль (всегда в промпте) и подтверждённые решения/знания (при совпадении темы вопроса). Факты сжатия Sticky Facts пишутся в долговременный слой автоматически и после двух подтверждений становятся «долговременными». Тумблер у каждого блока включает и выключает слой: выключенный слой не отправляется модели, как будто его нет, — данные при этом сохраняются. Корзина в шапке: «Удалить чат» — сообщения и краткосрочный слой (рабочая сохраняется), «Удалить историю» — краткосрочная и рабочая, «Удалить все» — все уровни, включая долговременный.
Блок показывает актуальное состояние задачи; этап и статусы шагов меняет только модель в диалоге (инструмент task_state). Переходы: planning → execution → validation → done (validation может вернуться в execution; из planning в done напрямую нельзя, отмена — reset из planning). Завершённая задача (done) остаётся записью об истории — чтобы убрать её из панели полностью, нажмите «Убрать из деталей» или попросите модель перевести задачу в reset.
