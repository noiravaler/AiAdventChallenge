# ai-chat-go — Task05

Веб-приложение, которое решает список задач **тремя моделями разных классов**
(маленькая / средняя / флагманская) и сравнивает их между собой: сколько задач
решено верно, скорость, ресурсоёмкость, стоимость и на каких задачах хватает
самой дешёвой модели. Написан на Go без внешних зависимостей (только
стандартная библиотека).

> Task05 — развитие идеи [Task03](../Task03/README.md), но вместо выбора
> способа/уровня рассуждения приложение прогоняет **все задачи по всем трём
> моделям** и строит сравнительный вывод. Пользовательский интерфейс упрощён:
> задачи свёрнуты в аккордеоны, настройки и выбор уровня рассуждения убраны.

## Возможности

- **Три модели** — блок «Модели» на панели:
  - **Маленькая модель** — `GPT-5 Nano` (готовый блоб, настройки и ключ
    берутся из конфига OpenCode, см. «Настройка»);
  - **Средняя модель** — выпадающий список моделей GPUStack (по умолчанию
    `qwen3.8-27b`), клик переключает модель через `POST /api/model`;
  - **Флагманская модель** — `DeepSeek-V4-Pro` (резервное подключение).
- **Список задач** — блок «Задача» со свёрнутыми аккордеонами: у каждой задачи
  видны «Условие» и «Ответ». Задачи (5 шт.):
  | Задача | Ответ |
  | --- | --- |
  | Голубоглазые островитяне (100 синих + 100 карих глаз, мудрец) | «Все 100 синеглазых покинут остров ровно на 100-ю ночь после объявления» |
  | Количество непрерывных подотрезков с суммой, равной `k` | `2` |
  | Точка `C` на оси абсцисс с минимальной `AC + CB` | `C(7/3; 0)` |
  | «Оба лжецы»: Иван и Стас (логическая) | `Иван` |
  | Вероятность: 6 красных и 4 синих шара, два без возвращения | `7/15` |
- **Запуск решения** — одна кнопка «Запустить решение»: **все задачи
  последовательно** для **всех трёх моделей** без дополнительных параметров.
  Таймаут одного запроса — 60 с.
- **Три таблицы результатов** — по одной на каждую модель, колонки:
  `Задача | Стоимость | Токены | Время | Успех | Детали`. В статусе «Успех» —
  зелёная галочка при верном ответе, красный крестик при неверном, иконка стоп
  при таймауте, иконка ошибки при сбое. «Детали» раскрывают ход решения модели.
- **Итоговая стоимость** — внизу каждой таблицы строка с суммой по всем
  запускам этой модели.
- **Расчёт стоимости** — по фактическим токенам запроса/ответа:
  `prompt_tokens/1e6 × ценаЗапроса + completion_tokens/1e6 × ценаОтвета`.
  Цены за 1М токенов:
  | Модель | Запрос | Ответ |
  | --- | ---: | ---: |
  | Маленькая | 2,97 ₽ | 23,74 ₽ |
  | Средняя | 20,34 ₽ | 122,05 ₽ |
  | Флагманская | 38,67 ₽ | 77,34 ₽ |
- **Блок «Вывод»** — после всех запусков выбранная средняя (GPUStack) модель
  анализирует результаты и отвечает: сколько задач решено верно каждой моделью,
  скорость, ресурсоёмкость, во сколько раз флагманская дороже маленькой и
  насколько она точнее, а также на каких задачах маленькой модели достаточно.
- **Гибкая проверка ответа** (`/api/solve`) — ответ сравнивается с ожидаемым с
  учётом разных написаний, LaTeX-символов, дробей и объяснений; для
  числовых/координатных ответов допускается эквивалентность значений.
- **Флагманская модель без задержек** — `deepseek-v4-pro` по умолчанию
  рассуждает на уровне `high` (длинные цепочки, 30–60 с на задачу); при
  решении задачам флагмана принудительно ставится `reasoning_effort: low`,
  чтобы ответ был быстрым.
- **Локальный сервер с `go:embed`** — страница встроена в бинарник, поэтому
  любые правки `static/index.html` требуют пересборки.

## Требования

- Go 1.22 или новее.

## Быстрый старт

```sh
cd Task05
cp .env.example .env
# откройте .env и впишите AI_API_KEY
go run ./app
```

Или без файла `.env`:

```sh
export AI_API_KEY="sk-..."
go run ./app
```

> Примечание: репозиторий Task05 не содержит `.env` — реальная конфигурация
> обычно берётся из `../Task02/.env` (источник `AI_BASE_URL`, `AI_MODEL`,
> `AI_MODELS`, ключей резервного провайдера). Секреты в `.env` исключены через
> корневой `.gitignore`.

### Маленькая модель (GPT-5 Nano)

По умолчанию настройки маленькой модели берутся автоматически из конфига
OpenCode: ищется провайдер, у которого в списке `models` есть `gpt-5-nano`, и
читаются его `baseURL` и `apiKey` (на уровне провайдера или в `options`).
Плейсхолдеры ключей вида `{env:NAME}` раскрываются из окружения. Явные
`AI_SMALL_BASE_URL` / `AI_SMALL_API_KEY` / `AI_SMALL_MODEL` перекрывают конфиг.

### Веб-интерфейс

При запуске без аргументов сервер поднимается на `http://127.0.0.1:5190` и
открывается в браузере. Если порт занят — берётся следующий свободный. Сервер
слушает только `127.0.0.1`.

На странице:

- **Модели** — три блока: Маленькая (`GPT-5 Nano`), Средняя (выпадающий список),
  Флагманская (`DeepSeek-V4-Pro`).
- **Задача** — аккордеоны задач (клик раскрывает «Условие» и «Ответ»).
- **Запустить решение** — кнопка запуска всех задач всеми моделями.
- **Решения** — три таблицы (по одной на модель) с колонками
  `Задача | Стоимость | Токены | Время | Успех | Детали` и строкой
  «Итоговая стоимость» внизу.
- **Вывод** — сравнительный анализ моделей, формируемый средней моделью после
  завершения всех запусков.

## Как это работает

Клиент отправляет `POST {AI_BASE_URL}/chat/completions` в формате OpenAI Chat
Completions. «Маленькая» и «Флагманская» модели ходят на свои отдельные
эндпоинты: маленькая — на провайдера из конфига OpenCode (по умолчанию
Polza / GPT-5 Nano), флагманская — на резервного провайдера
(по умолчанию DeepSeek / DeepSeek-V4-Pro). Средняя — на основной GPUStack.

`POST /api/solve` выполняет один запуск: принимает `{condition, expected,
timeout, model}` (модель `small`/`mid`/`flagship` или имя из списка),
ограничивает таймаутом 10–60 с (по умолчанию 60) и возвращает
`{method, name, tokens, prompt_tokens, completion_tokens, duration, success,
timed_out, solution, prompt, error}`. Токены `prompt_tokens` / `completion_tokens`
используются для расчёта стоимости. Успех определяется гибким сравнением ответа
с ожидаемым (`answersMatch`). Флагманской модели при отсутствии явного
`reasoning` подставляется `reasoning_effort: low`.

`POST /api/conclusion` принимает `{results: [...], prices: {...}}` — все запуски
всех моделей и цены за 1М токенов — и возвращает `{analysis}`: сравнительный
вывод по числу решённых задач, точности, скорости, ресурсоёмкости и разнице в
цене между флагманом и маленькой моделью, а также список задач, где достаточно
маленькой модели. Анализ строит выбранная средняя (GPUStack) модель.

`GET /api/info` отдаёт текущую модель, лимит токенов и готовность маленькой и
флагманской моделей. `GET /api/models` — список моделей среднего уровня, а
`POST /api/model` переключает текущую модель.

Страница (`go:embed`) строит аккордеоны, три таблицы с ценами, считает
«Итоговую стоимость» и «Вывод», отправляя запросы в API и отрисовывая ответ
лёгким Markdown-парсером (`renderMarkdown`), включая таблицы и LaTeX-формулы.

## Безопасность

- `.env`, `.idea/` и `bin/` уже в корневом `.gitignore` — правило действует для
  всех папок задач, поэтому секреты и артефакты не попадают в репозиторий.
- Не передавайте ключ флагом `-api-key` в общих системах: он остаётся в истории
  shell.
- Ключ и переписка не пишутся на диск; детали запроса/ответа хранятся только в
  памяти и отдаются в панель «Детали», сам ключ в них не попадает.
